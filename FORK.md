# Fork pessoal do OpenSquad

Este repositório é o fork pessoal de Eduardo do OpenSquad.

- `origin` aponta para `bertassi/opensquad`, o fork pessoal.
- `upstream` aponta para `renatoasse/opensquad`, o projeto original.
- `master` é a branch principal do fork e contém suas adaptações.

Para incorporar atualizações do projeto original, busque `upstream/master`,
revise as mudanças e integre-as à `master` do fork. Após os testes, publique
somente em `origin` e sincronize as máquinas. Não envie alterações ao `upstream`.
